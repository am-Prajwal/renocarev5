# Renocare Contracting Website

Static 4-page website ready for Vercel.

## Pages
- Home `/`
- About Us `/about/`
- Our Services `/services/`
- Testimonials & Recent Work `/testimonials/`

## Deploy to Vercel
1. Unzip this project.
2. Go to Vercel and create a new project.
3. Upload/import this folder or push it to GitHub and import the repository.
4. Framework preset: **Other**.
5. Build command: leave blank.
6. Output directory: leave blank / project root.
7. Deploy.
8. Add `renocare.ca` and `www.renocare.ca` under Project → Settings → Domains.
